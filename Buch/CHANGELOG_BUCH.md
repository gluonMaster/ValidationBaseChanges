# Изменения в модулях Buch (декабрь 2025)

## Ручные действия (требуется выполнить в редакторе VBA)

### Добавить кнопку на форму frmZahlBrief

1. Открыть форму `frmZahlBrief` в редакторе VBA (Alt+F11)
2. Добавить новую кнопку `CommandButton`
3. Установить свойства:
   - **Name**: `btnLast3Years`
   - **Caption**: `Letzte 3 Jahre`
4. Разместить кнопку рядом с существующей кнопкой OK

> Обработчик `btnLast3Years_Click` уже добавлен в код формы.

## Инструкция для пользователя

### Импорт данных

- **ImportFromBase** / **ImportFromBase_Default** — импорт из Access для 2024-2026
- **ImportFromBase_Extended** — полный импорт 2023-2026 (2023 из Excel-файла)

### Отчёты Kosten

- **Кнопка OK** — отчёт за все годы (2023-2026)
- **Кнопка "Letzte 3 Jahre"** — отчёт только за 2024-2026

### Экспорт/импорт модулей

- `ModuleExporter.ExportAllModules` — экспорт .bas модулей
- `ModuleExporter.ExportAllModulesAndClasses` — экспорт .bas и .cls
- `ModuleImporter.ImportModules` — выбор файлов для импорта
- `ModuleImporter.ImportModulesFromFolder` — импорт всех модулей из папки

> **Важно**: Для работы экспорта/импорта модулей необходимо включить доступ к VBA-проекту:  
> Файл → Параметры → Центр управления безопасностью → Параметры макросов → ✓ Доверять доступ к объектной модели проектов VBA
