# Ind-Blanks (KindElternDaten_25_Admin.xlsm)

## Назначение
Макрос `indBlank_GenerateIndBlanksFromFilteredKartei` создаёт `.xlsx` бланки для учителей индивидуальных занятий на основе **видимых** строк листа `Kartei` (учитывает и AutoFilter, и ручное скрытие строк).

## Предварительные условия
- Макрос запускается из `KindElternDaten_25_Admin.xlsm`.
- Шаблон лежит по пути `C:\temp\ShablonInd.xlsx` и содержит лист `Muster`.
- Пользователь предварительно фильтрует `Kartei` по дисциплине:
  - месяцы `1–6`: колонка `J`
  - месяцы `7–12`: колонка `O`

## Какие строки обрабатываются
Обрабатываются только строки `Kartei`, которые:
- находятся начиная с строки `3`
- **не скрыты** (`Rows(r).Hidden = False`)
- в дисциплине (колонка `J` или `O`) имеют формат:
  - `Ind ...` / `Ind. ...` (например `Ind. Ma Mo 3kl`, `Ind Ma`, `Ind. Sachunt ...`)
  - или `VSpE_...` (например `VSpE_Elena`)

## Парсинг дисциплины
- `VSpE_Elena` → `VSpE`
- `Ind. Ma Mo 3kl` → `Mathe` (используется только первый токен после `Ind`)
- Маппинг:
  - `Ma` → `Mathe`
  - `Ru` → `Russisch`
  - `Eng` → `Englisch`
  - `De` → `Deutsch`
- Если маппинг не найден (например `Ind. Sachunt ...`) → подставляется `Sachunt`.

## Откуда берутся данные на Kartei
- Ребёнок: `Kartei!D` (строка вида `Nachname ; Vorname`, разделители `; , .` превращаются в пробелы)
- Дисциплина: `Kartei!J` (месяцы `1–6`) или `Kartei!O` (месяцы `7–12`)
- Учитель: `Kartei!K` (месяцы `1–6`) или `Kartei!P` (месяцы `7–12`)

## Куда сохраняются файлы
- Пользователь выбирает базовую папку.
- Для каждого учителя создаётся подпапка по имени учителя (если учитель пустой — `Unsorted`).
- Файлы сохраняются как `.xlsx`; если имя уже занято, добавляется суффикс `_2`, `_3`, ...

## Что заполняется в шаблоне
Лист `Muster` копируется в новый `.xlsx` и заполняется:
- `B1` = полное имя ребёнка
- `E1` = дисциплина
- `C4` = месяц (вводится пользователем через InputBox)
- `E4` = год (вводится пользователем через InputBox)
Ячейка `B2` не заполняется.

## Важно про месяц и колонки
- Макрос спрашивает месяц (1-12) и по нему выбирает колонки:
  - `1–6`: дисциплина `J`, учитель `K`
  - `7–12`: дисциплина `O`, учитель `P`
