# Инструкция по индексации зарплат

## Августовская индексация

**Запуск:** `indx_Main`

| Параметр               | Значение              |
| ---------------------- | --------------------- |
| Исходная колонка (War) | AB (August)           |
| База для расчёта       | AC (September)        |
| Формула                | `Round(0.75 × AC, 2)` |
| Запись результата      | AB                    |

**Лист Indexation:**
| A | B | D | O | S | Aug War | Aug Wird | Sept |
|---|---|---|---|---|---------|----------|------|

---

## Декабрьская индексация

**Запуск:** `indx_DecemberMain`

| Параметр               | Значение              |
| ---------------------- | --------------------- |
| Исходная колонка (War) | AF (Dezember)         |
| База для расчёта       | AF (Dezember)         |
| Формула                | `Round(0.75 × AF, 2)` |
| Запись результата      | AF                    |

**Лист Indexation:**
| A | B | D | O | S | Dez War | Dez Wird | _(пусто)_ |
|---|---|---|---|---|---------|----------|-----------|

---

## Критерии отбора записей (общие)

- Колонка **S** содержит `O/V` (без учёта регистра)
- Колонка **T** НЕ содержит `KN` (без учёта регистра)

## Порядок работы

1. Открыть книгу `KindElternDaten_25_Admin.xlsm`
2. Запустить нужный макрос (`indx_Main` или `indx_DecemberMain`)
3. Проверить данные на листе **Indexation**
4. Нажать кнопку **OK** для применения изменений
5. Лист Indexation автоматически удаляется, фокус возвращается на Kartei

## Структура модулей

| Модуль                      | Назначение                   |
| --------------------------- | ---------------------------- |
| `indx_Main.bas`             | Точка входа для августа      |

| `indx_ButtonHandler.bas`    | Legacy-обработчики кнопок    |
| `indx_Utils.bas`            | Вспомогательные функции      |
| `indx_FilterUtils.bas`      | Работа с фильтрами           |
