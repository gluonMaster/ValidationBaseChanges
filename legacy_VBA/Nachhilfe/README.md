# Nachhilfe2425.xlsm – Kinder Cleanup (Kind_\*)

## Назначение
Макрос `Kind_CleanupKinder` удаляет строки на листе `Kinder`, если для этой записи найдена **ровно одна** соответствующая запись на листе `Kartei` (в уже открытом файле `KindElternDaten_25_Admin.xlsm`) и у нее в колонке `T` стоит статус `KN` (проверка регистронезависимая).

## Предварительные условия
- Файл админа `KindElternDaten_25_Admin.xlsm` **должен быть уже открыт**. Макрос его не открывает.
- В `Nachhilfe2425.xlsm` должны существовать листы:
  - `Kinder` (данные начиная с 5-й строки)
  - `ErrorLog` (логирование идет в колонки `E:K`, колонки `A:C` не трогаются)

## Как запустить
1. Откройте `KindElternDaten_25_Admin.xlsm`.
2. Откройте `Nachhilfe2425.xlsm` и перейдите на лист `Kinder`.
3. Запустите макрос `Kind_CleanupKinder` (кнопку можно привязать вручную).

## Правила сопоставления
- На `Kinder` используются колонки:
  - `B` = `FamilyID`
  - `C` = Nachname
  - `D` = Vorname
  - `E` = Fach
- На `Kartei` используются колонки:
  - `A` = `FamilyID`
  - `D` = Child (например `Asmus ; Leonard`, разделитель может быть `;`, `,`, `.` или пробел)
  - `T` = статус (`KN`)
  - Fach:
    - текущий месяц `1–6`: колонка `J`
    - текущий месяц `7–12`: колонка `O`
- Предмет на `Kartei` учитывается **только** если он начинается с `Nachhilfe` или `NH` (регистронезависимо). Префикс отбрасывается, дальше сравнение идет по базовому названию предмета.
  - Если после названия предмета в `Kartei` стоят дополнительные пометки (например `NH Deutsch Mo 3kl`), для сопоставления используется только первое слово после префикса (в примере: `Deutsch`).

## Что пишется в ErrorLog
Записи, которые **не удаляются**, но требуют внимания, логируются в `ErrorLog`:
- не найдено сочетание `FamilyID + Fach` на `Kartei` (`NO_KEY`)
- `FamilyID + Fach` найдено, но ребенок не совпал по имени (`NO_CHILD`)
- найдено более одного совпадения по ребенку (`AMBIGUOUS`)
- ошибки выполнения (`RUNTIME_ERR`)

## Примечания
- Удаление делается через `EntireRow.Delete` (обход снизу вверх).
- На время работы отключаются `ScreenUpdating`, `EnableEvents` и устанавливается `Calculation = Manual`; после завершения состояние восстанавливается (класс `Kind_AppState`).
